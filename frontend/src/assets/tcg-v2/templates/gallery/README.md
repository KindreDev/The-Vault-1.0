# Gallery — scrapbook Polaroid

The Gallery card represents one real Vault gallery (one folder on disk). Its frozen recipe stores the gallery, source image, optional assigned creator, optional period, palette, rarity, and mint identity.

Layer order is deliberately stable: paper, source photograph, Polaroid, tape, motifs, printed text, rarity, and optional SPR signature. The photograph remains independent from every decorative layer so future foil effects can target them separately.

Missing creator or period metadata is omitted; the renderer never invents either value.
