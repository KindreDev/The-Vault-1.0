# Collab card template

The Collab card uses the accepted physical gold gift-frame language while keeping the photograph, frame, rarity, text, and optional SPR signature as separate runtime layers. The frame never inserts decorations across the interior photograph, so multi-person compositions retain their faces and bodies.

The lowered top field is reserved for verified character names and is omitted when no characters are assigned. Gallery/set names never leak into that field. The lower plate identifies every verified creator once, joined with `×`. Missing characters or creators are never invented.
